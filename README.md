# 🌍 Wanderlust Adventures - Travel & Tour Website

A modern, responsive, and interactive travel website built using HTML, CSS, and JavaScript. The website allows users to explore destinations, browse travel packages, view customer reviews, and simulate package bookings through an intuitive user interface.

## 📌 Project Overview

Wanderlust Adventures is a premium travel and tourism website designed to provide users with an engaging travel booking experience. The project features destination showcases, tour package filtering, booking forms, testimonials, dark/light mode, and responsive design.

## ⚙️ AWS Deployment

### Infrastructure Used

- AWS EC2 (Ubuntu Server)
- Nginx Web Server
- Security Groups
- SSH Access

### Deployment Steps

1. Launch EC2 Instance
2. Connect using SSH
3. Install Nginx
4. Upload website files
5. Configure web root
6. Start Nginx service
7. Access website via Public IP
